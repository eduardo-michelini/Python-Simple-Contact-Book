# Python-Agenda-De-Contatos-Simples
Uma agenda de contatos simples e prática feita em Python. Você pode adicionar, listar, buscar e remover contatos com validação de número de telefone em tempo real. Aproveite!

Explicação:

Setup: Pede o seu nome de usuário e inicializa um dicionário vazio para armazenar os contatos.

Loop: Mantém o programa rodando através de um menu interativo até que você escolha a opção 5 para sair.

Adição com Validação: Permite cadastrar um novo contato exigindo o formato exato com 17 caracteres.

Listagem e Busca: Permite visualizar a lista completa ou buscar um contato específico pelo nome.

Exclusão e Encerramento: Permite remover contatos existentes do dicionário e encerrar o programa com mensagem de despedida.

# Python-Simple-Contact-Book
A simple and practical Contact Book made with Python. You can add, list, search, and delete contacts with real-time phone number format validation. Enjoy!

Explanation:

Setup: Asks for your username and initializes an empty dictionary to store contact details.

Loop: Keeps the program running through an interactive menu until you select option 5 to exit.

Addition with Validation: Allows you to register a new contact requiring an exact 17-character format.

Listing & Search: Enables you to view the full contact list or search for a specific contact by name.

Deletion & Exit: Allows deleting existing contacts from the dictionary and closing the program cleanly.
