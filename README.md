# Python-Simple-Contact-Book

A simple and practical Contact Book made with Python. You can add, list, search, and delete contacts with real-time phone number format validation. Enjoy!

Explanation:

1. Setup: Asks for your username and initializes an empty dictionary to store contact details.
2. Loop: Keeps the program running through an interactive menu until you select option 5 to exit.
3. Addition with Validation: Allows you to register a new contact requiring an exact 17-character format.
4. Listing & Search: Enables you to view the full contact list or search for a specific contact by name.
5. Deletion & Exit: Allows deleting existing contacts from the dictionary and closing the program cleanly.

# Python-Agenda-De-Contatos-Simples

Uma agenda de contatos simples e prática feita em Python. Você pode adicionar, listar, buscar e remover contatos com validação de número de telefone em tempo real. Aproveite!

Explicação:

1. Setup: Pede o seu nome de usuário e inicializa um dicionário vazio para armazenar os contatos.
2. Loop: Mantém o programa rodando através de um menu interativo até que você escolha a opção 5 para sair.
3. Adição com Validação: Permite cadastrar um novo contato exigindo o formato exato com 17 caracteres.
4. Listagem e Busca: Permite visualizar a lista completa ou buscar um contato específico pelo nome.
5. Exclusão e Encerramento: Permite remover contatos existentes do dicionário e encerrar o programa com mensagem de despedida.
